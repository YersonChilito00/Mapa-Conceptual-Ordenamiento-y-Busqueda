# Métodos de ordenamiento: mapa conceptual y diagramas de flujo

Página web interactiva (HTML, CSS y JavaScript, sin dependencias) con:

- **Mapa conceptual** de los métodos de ordenamiento: burbuja, sacudida, selección, inserción, MergeSort, QuickSort y HeapSort, más **Shell Sort** como algoritmo adicional. Cada uno muestra nombre, descripción, Big O y eficiencia.
- **Diagramas de flujo** con su **pseudocódigo**.
- **Tabla comparativa** de complejidad, estabilidad y uso de memoria.

## Cómo usarlo

Abre `index.html` en cualquier navegador. No necesita instalación ni conexión a internet.

## Publicarlo con GitHub Pages

1. Sube los archivos a un repositorio.
2. En **Settings → Pages**, elige la rama `main` y la carpeta `/ (root)`.
3. La página quedará disponible en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
